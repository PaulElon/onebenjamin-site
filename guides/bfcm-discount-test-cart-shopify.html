Black Friday discount check: build a test cart before the sale

Most Black Friday discount problems are not one bad discount. They are two or three good ones landing on the same cart. A store owner in the Shopify Community described it:

"On a handful of carts all three landed at once and we shipped orders below cost." (an automatic 20% on a collection, an email code, and free shipping over $75; Shopify Community)
"This mean some products get a 60% discount which is completely unacceptable." (an abandoned-cart code on top of sale prices; Shopify Community)

This checklist takes about an hour and costs nothing. Do it a few days before the sale starts, and again after any discount is added.

1. List every discount that will be live

Open Discounts in your admin and write down every active or scheduled discount for the sale window. Include the ones people forget:

  • Automatic discounts (they apply with no code).
  • Free shipping thresholds.
  • Codes made by apps: influencer, affiliate, loyalty, referral, abandoned-cart and pop-up codes. One merchant had "100's of discount codes that are active at anyone time" (source).
  • Staff and wholesale codes that customers sometimes share.
  • Products shown at a sale price with a compare-at price. Shopify does not treat a compare-at price as a discount, so discounts can still apply on top of it.

2. Write down each discount's class and combinations

Shopify sorts discounts into three classes: product (money off items), order (money off the whole purchase), and shipping. Each discount has a Combinations setting that says which of those classes it may combine with. For each discount on your list, note:

Write downWhy it matters
Class (product, order, shipping)Combinations are set per class, not per discount.
Combines with: product / order / shippingTwo discounts stack only if their settings allow it.
Applies to (all products, collections, products)Tells you which items each one can reach.
Minimum purchase or quantityA cart just over the threshold is the one to test.
Usage limits"One use per customer" and total-use limits stop code sharing from getting out of hand.

Shopify's developer docs add one rule worth knowing: by default, only one product discount applies to a single cart line. (Shopify Plus stores can let tagged product discounts apply together on a line.) An order discount and a shipping discount can still land on top if the settings allow.

3. Build the test carts

Use your store as a customer would. You do not need to place an order: checkout shows the discounts and the total before payment. Build these carts and write the total next to each:

  1. The worst case. One sale-priced item from the discounted collection, enough to pass the free-shipping and minimum-purchase thresholds, plus your biggest code. Compare the total to your cost.
  2. Each code on a sale item. Every code type from step 1 (one influencer code, one loyalty code, and so on) on a single compare-at item.
  3. Each protected product. Anything that should never be discounted (new arrivals, gift cards, low-margin items) with each code.
  4. Just over each threshold. A cart a dollar over each minimum, then remove one item and check the discount goes away.
  5. Express checkout. Repeat the worst case through an express button such as Shop Pay, if you offer it.

If any total is below what you can afford, fix the discount, not the cart: turn off a combination, narrow Applies to, or set a usage limit.

4. Common fixes

  • Code stacks on sale items: point the code at a collection that leaves sale items out. Step-by-step: how to exclude products from a Shopify discount.
  • Order discount plus free shipping goes below cost: untick shipping in the order discount's combinations, or raise the free-shipping threshold for the sale.
  • A shared code is used hundreds of times: set a total-use limit or "one use per customer".
  • Quantity limits for drops: see limit quantity per order and limit to one per customer.

5. On the day

  • Rebuild the worst-case cart once the sale starts. Scheduled discounts and app codes can switch on at different times.
  • Check the first few orders' discount lines against what you expected.
  • Keep the list from step 1. It is your undo list if something goes wrong.
