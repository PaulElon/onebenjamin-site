How to exclude products from a Shopify discount

You want "20% off everything except the new collection" or "this code should not work on items already on sale". Merchants ask for it all the time:

"No native way to exclude specific products or SKUs, only include them." (Shopify Community)
"How to stop Shopify stacking discounts on items that are already on sale? Surely this should be native." (Shopify Community)

Short answer

A Shopify amount-off discount has no "exclude" field. Under Applies to you pick Specific products or Specific collections, or the discount applies to all products. So the native way to exclude items is to flip the problem: build a collection that holds everything except the items you want to protect, and point the discount at that collection.

The native workaround, step by step

  1. Mark the items to protect. Give them a tag such as no-discount, or keep them in their own collection (for example "New arrivals").
  2. Create a collection called "Discount eligible". In Products > Collections, add a Products source that includes your products by condition (for example, product status is equal to Active).
  3. Exclude the protected items. In that source, click Exclude and either add the condition Tag includes no-discount, or exclude the existing collection of protected items. Shopify says exclusions always override inclusions.
  4. Point the discount at it. Create or edit your discount, set Applies to to Specific collections, and choose "Discount eligible". This also works for a code you have already shared: edit the existing discount and save.

Excluding sale items (compare-at price)

Collections can match on Compare at price is not set, which keeps out products shown at a sale price. Three catches from Shopify's own docs:

  • A product matches "is not set" when any of its variants has an empty compare-at price. If only some variants are on sale, the product still gets into the collection, and the discount reaches the sale variants too.
  • A compare-at price of $0.00 does not count as empty.
  • Compare-at price cannot be used in the Exclude section. Shopify lists only category, tag, type, and vendor conditions for exclusions, so it has to be an include condition.

The reliable fix is a tag: tag sale items sale (by hand or with bulk edit) and exclude the tag.

Limits of the workaround

LimitWhat it means
Exclusions work on productsShopify describes exclusions as removing products from the collection. If only some variants of a product are on sale, plan for the variant catch above.
60 condition values per sourceFine for a few tags; tight if you exclude long lists by title or vendor.
5 collections per store that exclude another collectionIf you run many campaigns with different exclusions, use tags instead of collection exclusions.
"Match any" vs "Match all"Shopify warns that with "Match any condition" a product can stay in even if it matches some exclusion criteria. Use "Match all" for exclusions, or a single tag.
UpkeepOne "eligible" collection per exclusion set. Each new product needs the right tag before the next sale.
StackingWhether your code also combines with other discounts is set separately, in the discount's Combinations section.
